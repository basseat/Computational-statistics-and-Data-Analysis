## Exercise Sheet 3 – Regression, Logistic MLE, and Standard Error Scaling

Applies multivariate linear regression to the UCI Wine Quality dataset using a least squares estimator via matrix inversion. Estimates logistic regression parameters using both maximum likelihood and least squares on a sigmoid model. Investigates standard deviation bias and standard error scaling (1/√N) via Monte Carlo simulation on exponential samples.

**Libraries:** NumPy, SciPy, Pandas, Matplotlib, SymPy
